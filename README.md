# odin-calculator

## Description
A fully functional, logic-driven web calculator built with vanilla JavaScript, HTML, and CSS. This project serves as a capstone for foundational JavaScript, focusing on handling complex user input sequences, mathematical logic, and real-time UI updates

## Skills Demonstrated
- Complex Logic Flow: Designed an "operate" function to manage the relationship between first operands, operators, and second operands.
- State Management: Successfully tracked and updated variables representing the current display, the stored value, and the selected operator throughout the calculation lifecycle.
- Data Sanitization & Validation: Implemented logic to prevent common UI bugs, such as multiple decimal points in a single number or non-sensical operator sequences.
- String Manipulation: Managed the calculator display by converting numerical results to strings for formatting (rounding) and UI rendering.
- Advanced Event Listening: Implemented global event listeners to map physical key presses to on-screen functions.
- UI/UX Design: Used CSS (Flexbox) to create a responsive and intuitive interface that mimics a physical calculator.
